## Sample 3 — Verbose 'rules-in-prompt' envelope · Day 1 night

Your single dominant failure mode is *over-deliberation*. You
enumerate 'option A vs option B vs option C', argue yourself in
circles, run out of wallclock, and the heuristic takes the seat.
An UNSUBMITTED 'perfect' plan scores ZERO. A SUBMITTED 'good'
