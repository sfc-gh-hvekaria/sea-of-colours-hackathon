v7What v7 is

The release that fixed the root cause. Everything through v6 fought a language model that ran out of budget before it emitted a complete plan. v7 proved that was never a prompting problem — it was an API-surface problem — and switched surfaces.

The Cortex Agents API gives you exactly one budget control: a wallclock guillotine (close the socket at N seconds) over a think+answer budget the server divides, think-first. The Cortex inference API gives you three independent, server-honored dials: a hard max_completion_tokens answer ceiling, a separate reasoning.max_tokens think channel, and response_format: json_schema constrained decoding. v7 rebuilt the mover on the inference path — and then, crucially, rebuilt the thinker there too.

01The two engineering changes

✗ parked (Agents API)

The two-call split, attempt 1

A dedicated thinker commits a tiny DECISION directive; the mover executes it. Built + tested, kept behind a flag. Parked as a negative result: haiku thinks unbounded on the Agents API, so an 18s cap truncated the thinker every night ([thinker=none] 7/7) and a 50s cap broke the wall while landing a directive only ~2/7 nights — with a score regression (980 vs 1768).

✓ shipped (Inference API)

The contained split

Both passes move to CortexChatInvoker. The reasoning-first thinker emits one JSON object (reasoning FIRST, then a small directive) under a hard token cap; the moves-first mover emits a schema-guaranteed moves object. Separate budgets mean the think can't starve the answer, and constrained decoding means the answer is valid by construction.

The parked attempt is load-bearing: watching the thinker overrun its budget on the Agents API is what isolated the opaque-budget root cause and pointed at the inference API as the cure.

The handoff

Thinker (Call 1) → a sanitized DECISION directive (posture · targets · chaff_react · avoid · note) → injected as a STRATEGIST DIRECTIVE block at the top of the mover prompt (Call 2). The mover executes the directive; the sanitizer + heuristic net still guarantee legality. Any thinker failure yields an empty directive and the mover runs exactly as single-call — so the split is strictly ≥ single-call by construction.

03The "aha" — CoT salvage beats a bigger cap

Even contained, the reasoning-first thinker occasionally truncated its JSON on the densest multi-opponent nights (2/7 in an early scan). Two fixes, in order of importance:

  1. CoT salvage: _salvage_reasoning extracts the reasoning text even from a truncated, unparseable object — so the chain-of-thought is never lost for audit/scan, even when the directive is.
  2. Budget bump: thinker cap 2500 → 3600 tokens, wallclock 30 → 40s. After both, the seed-42 re-scan captured full reasoning + a directive on all 7 nights — the truncated nights disappeared.

Lesson: don't just raise the cap; make the valuable byproduct (the reasoning) recoverable regardless of where the model stops.

04Multi-agent observability

With two Cortex calls per turn, a single audit row hides half the story. v7 writes one SOC_AGENT_INVOCATION row per sub-agent: the thinker's captured reasoning + directive get their own row (via sub_invocations in the dispatch envelope, persisted by audit.write_invocation) before the mover's row. Both reasoning passes are visible in the UI and scannable offline (scripts/scan_thinker.py) — the "does it actually reason?" audit.
