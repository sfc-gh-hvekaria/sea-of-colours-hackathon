v6What v6 is

The comprehension release. It inherits v5's moves-first output contract (emit the moves array before any prose, so a truncated turn still ships a plan) and the move sanitizer, then adds three levers aimed at a single weakness: v5 could act but it couldn't reliably read the board or its own past.

It still runs on the Cortex Agents API with the "reason in your head" instruction — the only Agents-API setting that skips runaway extended thinking. That makes v6 fast and obedient, but it is fundamentally a collator of the deterministic hints we precompute for it, not a strategist. That ceiling is exactly what v7's containment fix and v8's worldview restructure were built to break.

01The three engineering changes

1 · Grounded reflection

v5 authored its "what happened last night" narrative from memory — and routinely got it wrong, inventing outcomes that never occurred. v6 feeds the engine-resolved truth into the prompt: actual banked points and concrete losses (chaff jam, probe crush, dawn crash), computed by a deterministic recorder that diffs the score ledger night-over-night. The schema then forces the agent to echo the exact number and name the gap cause. It can no longer confabulate a result.

2 · Fog-gated hot-drops with a precomputed comb path

A "hot drop" — launch a probe, then drop a harvester into the disk it just revealed, in the same night — only makes sense if the target is genuinely fogged. v6 gates on that (target_in_fog) and precomputes a blind serpentine comb over the probe's radius-4 disk: staying in-disk, avoiding known green, biased toward value. A hot drop becomes a ready-to-copy 6-cell chain instead of a timid 2-step gesture.

3 · Absorb-first-step (anti self-crush)

Dropping a harvester onto your own live probe destroys the probe. When a harvest chain follows a drop, v6's sanitizer absorbs the first step into the drop — rerouting the drop to the first step's cell — sparing the probe and keeping the chain intact. A deterministic guardrail for a mistake the model kept making.

02What it carried forward (and became foundational)

Moves-first contract (v5)

The moves array is emitted first. Started as pure truncation defense; every later version keeps it.

Move sanitizer (v1–v4 lineage)

Deterministic repair of illegal moves (off-grid steps, non-adjacency, orphaned chains, self-crush). v7 and v8 reuse it unchanged.

State-triggered doctrine (v5)

Strategy appendices (redsign, blue, beware-EMP/chaff, final-night supersede) appear only when live state calls for them. v8 forks and extends this.

Precomputed hint menu

Chains, comb paths, probe placements, supersede targets — arithmetic kept out of the token budget. Shared by every version since.

03The "aha" — a complete plan is not a smart plan

The v6 ceiling, stated plainly

"Reason in your head" buys you a fast, obedient collator of the hints you hand it — not genuine deliberation. v6 reliably harvests visible RED and combs probe disks, but on the Agents API there is no middle setting between runaway think and no think. To make the agent smarter you cannot just ask it to think harder — the API surface won't let you bound it. That realization is what pointed straight at v7.

v6's recurring failures — chaff blindness (scheduling pickups into a jam window night after night), unit-identity confusion, no multi-night planning — are all depth problems. Depth is precisely what a fast collator can't supply, and precisely what v7 (containment) and v8 (worldview + a real, bounded thinker) set out to add.

04How it plays — head-to-head reference

In the seed-42 three-way arena (v8 vs v7 vs v6), v6 is the slowest of the three cortex versions per turn (~20–29s) and finished last. Its orbit-planning heuristic had a bug that spent RED fuel green-flushing, ending the season negative — a factor that skews the raw margin but doesn't change the ordering.
